# NEURAXIS

> **Explore the Architecture of Intelligence.**

An interactive AI research & intelligence visualization environment built for engineers, researchers, and curious minds. NEURAXIS lets you explore neural architectures, transformer attention, semantic embeddings, autonomous agents, RAG pipelines, and machine learning evaluation — entirely in the browser.

## Status

🚧 Under active development. See `ARCHITECTURE.md` and `DEVELOPMENT.md` for details (coming soon).
